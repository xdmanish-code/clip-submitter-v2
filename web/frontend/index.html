Local Agent Setup Guide

Run automation safely on your local desktop

Step 1

Start Browser with Remote Debugging (Port 9222)

Run the command for your operating system to launch a dedicated automation browser profile:

Windows (PowerShell):
chrome.exe --remote-debugging-port=9222 --user-data-dir="$env:LOCALAPPDATA\ClipSubmitterChrome"
macOS (Terminal):
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir="$HOME/Library/Application Support/ClipSubmitterChrome"
Linux (Terminal):
google-chrome --remote-debugging-port=9222 --user-data-dir="$HOME/.config/ClipSubmitterChrome"

Log into your target platforms (Discord, Cleanframe, etc.) once in this dedicated automation window. Your sessions are securely preserved locally.

Step 2

Start the Application

In your terminal, navigate to the project directory and run:

npm start

npm start launches both the web dashboard and the local agent together. The agent connects automatically to the dashboard via WebSocket.
